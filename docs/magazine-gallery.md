# 原导航下的双列图文内容区

行程概览和美食推荐采用参考图中的双列竖图卡片，融入网站原有暖白底、森林绿文字和青绿色操作样式。顶部保留行程概览、预算明细、每日行程、住宿推荐、美食推荐、避坑指南、行程准备七个模块，恢复原来的宽屏页头及导出入口，不再将整个攻略限制在640像素，也不再把其他模块藏进更多菜单。

两类内容区最多1120像素宽，始终为双列卡片。图片保持原比例及自然高度，完整展示；图片尺寸、文字或点单提醒展开后，通过 ResizeObserver 更新卡片跨行高度，形成错落瀑布流。DOM和键盘顺序保持不变，未启用脚本时仍可浏览双列卡片，打印时展开全部卡片。

概览展示全部去重景点，卡片保留简介、日程信息和查看行程入口；美食展示全部去重菜品及饮食提醒，不按区域或三餐分类。移除上一版单卡轮播、分页和缩略图，不新增收藏或其他数据接口。图片继续提前加载，并复用现有页面缓存和24小时字节缓存。

`tests/test_gallery_ui.py` 验证七模块导航、导出及景点图片/日程对应关系；`tests/discovery.test.mjs` 验证图片尺寸变化、隐藏标签切换后的重排、概览图片预加载及与每日行程复用。浏览器验收覆盖独立攻略、攻略库和320/390/820/1440像素宽度，检查无横向溢出、卡片不重叠、导航宽度不变及查看行程跳转。
