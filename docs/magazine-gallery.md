# 白橙旅行杂志轮播

行程概览和美食推荐采用第二套设计参考：白底、橙色强调、平面竖版大图、图片下方的标题简介、左右分页箭头，以及带名称的缩略图导航。相邻卡片只露图片，不露出半截文字。主图和缩略图均完整显示图片；原图比例不同会留出底色，不裁切画面。

主界面保留「行程概览」「美食推荐」双标签，预算、每日行程、住宿、避坑、准备和导出入口位于页头「更多」菜单，进入其他板块后仍显示完整导航。旅行概况与方案依据收在概览下方。桌面和攻略库都沿用竖屏卡片宽度，移动端自适应。

概览支持缩略图、左右按钮、原生单选框键盘操作及触屏左右滑动，滑动不触发主卡片的日程跳转；美食保留原有原生横向滚动。图片继续复用提前加载、选中图片优先和24小时字节缓存，不新增图片服务或依赖。静态 HTML 与打印保持可读。

`tests/test_gallery_ui.py` 覆盖主图和缩略图对应关系、其他板块和导出入口；`tests/gallery-swipe.test.mjs` 覆盖触屏方向判断、首尾切换及防止误跳转。浏览器验收覆盖独立攻略、攻略库和320/390/768/1440像素宽度。参考图中的照片是设计示意，运行页面的照片来自实际搜索结果。
