# 山海全景首页

按用户选定的第一版参考图实现，入口为 `travelmate/index.html`。没有新增依赖，保留现有认证、聊天、历史和攻略流程。

- 青绿山水全景、白色导航和宋体标题，配米白色悬浮选择栏。
- 主表单包括出发地、目的地、出发日期、旅行天数、同行人数、人均预算和旅行偏好。同行人数与其他条件采用同样的字号与控件尺寸；出发日期必填，不允许早于浏览器本地今天，每次提交重新检查日期下限。
- 偏好使用美食寻味、名胜古迹、放松散心、自然风光、人文艺术等通用兴趣，不再将海边、山野等地理场景作为偏好。推荐卡片分别映射为放松散心、自然风光、美食寻味和名胜古迹，切换城市保留可复用的兴趣偏好。
- 城市使用内置的国内目的地列表；新增城市时更新列表。原有快速规划仍可在对话中填写其他条件。
- 点击“生成我的行程”将所选条件整理为完整需求，沿用现有 `/chat/stream`。预算按所选区间上限乘以同行人数，明确传递人均口径、全员总预算及包含范围。
- 同城出发与到达时阻止提交。认证初始化和生成期间禁用生成按钮，避免重复提交。
- 四张推荐卡分别选择三亚 / 放松散心、莫干山 / 自然风光、成都 / 美食寻味、大理 / 名胜古迹。只回填选择，不自动调用模型；保留日期、天数、人数及预算。
- 生成需求明确携带出发日期，并要求结合城市实际条件、日期、季节和可获得的天气预报规划；远期日期不能把气候特征当作实时预报。
- 随机目的地排除当前目的地和出发地；保留其他条件，用户确认后再生成。
- 首页隐藏文字输入框；进入对话后恢复输入、快速规划、语音和预设。返回首页保留已选条件，旅行手记继续使用真实历史。
- 桌面和平板使用四列、两行主表单；手机使用双列表单，其中日期与生成按钮各占完整一行，推荐区为双列。
