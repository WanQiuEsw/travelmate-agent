# 预算保存与当地美食

## 预算

在预算明细中编辑金额及全员预算上限，停止输入约半秒后自动保存；勾选计入状态或恢复方案金额后立即自动保存，无需点击保存按钮。界面显示等待保存、正在保存、保存成功或失败状态；保存期间可继续编辑，修改按顺序提交，避免旧请求覆盖新输入。点击 PDF、Markdown 和 HTML 导出时先完成待保存预算，保存失败时保留输入并阻止导出旧金额，恢复网络或继续编辑会再次尝试。多页面同时修改通过修订号返回冲突，不覆盖其他页面已保存内容，需按提示刷新处理。用户填写金额不作为实时商家报价。

数据与行前清单采用相同模式：会话 `budget_lists` 与独立攻略 `guide_versions.budget` 保存版本状态，金额使用整数分，未知金额为 null，不能当作免费。保存只修改预算，不自动改写原始行程、生成约束或查询证据。版本之间互不覆盖；删除聊天后独立攻略的预算仍保留。「恢复方案金额」恢复原生成值并自动保存。

启动时为旧 `guide_versions` 表补上可空的 `budget` 列，保留既有内容。新接口沿用账号归属检查及写请求的同源检查。保存校验金额范围、整数分、完整项目集合和重复编号。

离线 HTML 的预算修改后自动保存到当前浏览器，和在线账号分别保存，不自动回传账号或修改已下载的文件。清理浏览器数据会丢失该离线修改。

## 当地美食轮播

美食页采用大图卡片轮播与缩略图导航，不按区域、天数或早中晚分组。支持触屏滑动、上一道/下一道按钮、缩略图点选，以及轮播聚焦后的左右方向键、Home/End；选中图片、缩略图和序号同步，首尾按钮循环切换，单道菜时禁用翻页按钮。减少动态效果设置下直接切换，打印时展开所有菜品。

新攻略推荐去重后的当地特色菜品与小吃，day 留空、meal 为不限，不再自动补齐三餐。兼容历史攻略的 day/meal 字段，展示时合并各天菜品、去掉重复项及旧的通用三餐占位建议；保留具体菜品的点单提醒和全局饮食要求，不改变保存方案、已订用餐或费用。

每道菜的大图和缩略图使用相同的“目的地＋菜名”小红书搜索配图接口，共享已有串行队列与缓存，只加载可见图片。搜索、登录或下载失败时显示明确占位，不用其他菜品冒充。离线 HTML 不请求在线配图，保留菜品与切换功能。容器查询适配桌面、手机及攻略库侧栏。

## 验证

`tests/test_food_ui.py` 覆盖历史菜品去重、三餐占位过滤、内容转义、空数据、饮食要求、配图链接、离线展示与不补齐三餐；`tests/food-photos.test.mjs` 验证缩略图/按钮/键盘/滑动状态、首尾循环和图片请求共享、串行加载及失败占位。预算测试仍在 `tests/test_budget.py`。

浏览器验证使用独立模拟攻略，不修改用户数据库。真实小红书配图依赖有效登录配置与服务可用性。
