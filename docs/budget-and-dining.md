# 预算保存与当地美食

## 预算

在预算明细中编辑金额及全员预算上限，停止输入约半秒后自动保存；勾选计入状态或恢复方案金额后立即自动保存，无需点击保存按钮。界面显示等待保存、正在保存、保存成功或失败状态；保存期间可继续编辑，修改按顺序提交，避免旧请求覆盖新输入。点击 PDF、Markdown 和 HTML 导出时先完成待保存预算，保存失败时保留输入并阻止导出旧金额，恢复网络或继续编辑会再次尝试。多页面同时修改通过修订号返回冲突，不覆盖其他页面已保存内容，需按提示刷新处理。用户填写金额不作为实时商家报价。

数据与行前清单采用相同模式：会话 `budget_lists` 与独立攻略 `guide_versions.budget` 保存版本状态，金额使用整数分，未知金额为 null，不能当作免费。保存只修改预算，不自动改写原始行程、生成约束或查询证据。版本之间互不覆盖；删除聊天后独立攻略的预算仍保留。「恢复方案金额」恢复原生成值并自动保存。

启动时为旧 `guide_versions` 表补上可空的 `budget` 列，保留既有内容。新接口沿用账号归属检查及写请求的同源检查。保存校验金额范围、整数分、完整项目集合和重复编号。

离线 HTML 的预算修改后自动保存到当前浏览器，和在线账号分别保存，不自动回传账号或修改已下载的文件。清理浏览器数据会丢失该离线修改。

## 当地美食图文卡片

美食页在原有七模块导航下以双列图文卡片展示所有去重菜品，不按区域、天数或早中晚分组，不再自动补齐三餐。旧攻略保留具体菜品的点单提醒和全局饮食要求，过滤旧的通用三餐占位建议，不改变保存方案、已订用餐或费用。

每道菜只加载一张对应搜索配图，随攻略打开提前排队，复用已有串行队列、内存和24小时磁盘缓存；失败时显示明确占位。图片按原比例自然高度完整显示，内容变化时更新瀑布流，不增加新依赖。离线 HTML 不请求在线配图，打印展开所有卡片。布局及验证见 [双列图文内容区](magazine-gallery.md)。
