# 美食路线参考稿分析与本次改进

分析日期：2026-11-04。参考文件为用户提供的《北京到上海3天2晚-美食路线.md》。只分析文档内容，不把其中的查询声明当作实际调用记录。

## 值得借鉴

1. 先给判断，再给方案。把往返交通作为预算的重要约束，用户容易理解取舍。
2. 围绕“喜欢吃”组织每日路线，把景点作为用餐之间的顺路活动；比景点清单外加一段美食更贴合需求。
3. 交通、住宿、每日表格、美食清单、费用账本和备选分开，便于手机阅读和保存。
4. 每日费用能与主线账本对应：三天分别为 1398、856、1342 元，合计 3596 元，加两晚住宿 700 元为 4296 元；5000 元减去该小计为 704 元。

## 需要改进

- **缺少日期却给精确承诺。** 用户只说玩三天，没有出发日、到离时刻及交通偏好，不能把特定车次、票价、小时表当作已经可执行的方案。铁路票价以购票时执行票价为准，预售期也有明确限制。[12306运输规程](https://kyfw.12306.cn/otn/gonggao/saleTicketMeans.html)
- **部分预算不能复算。** 品质档若沿用主线二等座 2212 元、住宿 800×2、餐饮 400×2×3、门票和市内交通 158 元，合计应为 6370 元；文中 6812 元尚有 442 元未解释。市内交通又出现“约150元”和账本78元两种口径。场景比较需统一人数、晚数、交通席别及预算范围。
- **实际场馆信息可能已过期。** 当前馆方参观须知对人民广场馆特展期间实行购票参观，不能沿用参考稿中的免费安排；应区分馆区、展览及当日公告。[上海博物馆参观须知](https://www.shanghaimuseum.cn/mu/frontend/pg/service/visit-west)
- **“已核实”缺少追溯依据。** 只写查询日期及“来自点评/榜单”不足以支撑地址、营业、价格与余票；需要保留真实查询结果、对应日期和公开链接。文档本身无法证明调用了多少 MCP，也无法证明对方没有天气能力。
- **用餐密度偏高。** 第二天汤包、小笼、本帮菜、咖啡、另一顿本帮菜，菜式也重复。两人应考虑少量分享、正餐轻重搭配、排队和消化时间。
- **绝对化判断过多。** “便宜一半”“溢价三倍”“一定能改少糖”“候补成功率不低”等缺少依据，容易把体验偏好写成事实保证。
- **天气和降雨备选没有绑定日期。** 通用雨天方案可以提前给，但不等于实时预报；室内备选仍需确认开放、购票和预约条件。

## 已落实到项目

- 统一输出顺序：先说结论 → 旅行概览 → 预算怎么用 → 交通与住宿 → 每日顺路表格 → 美食清单 → 备选 → 行前准备 → 公开来源。
- 聊天与版本预览、版本 Markdown 共用同一份保存内容，避免各自拼接出不同的预算或路线。已有 PDF 也使用这份版本数据生成。
- 每天保留日期、星期与天气。没有日期或没有有效预报时说明边界；不编造天气。
- 美食条目可关联第几天和哪一餐，生成时要求美食偏好进入每日路线，避免连续重餐。住宿只提供有依据的片区和筛选建议，缺少查询时不编造房态与价格。
- 首次信息不完整时先给草案；步数不再必填，预算口径和包含范围仍确认，防止把5000元误当作人均或总价。
- 支持选中回答和版本攻略的 Markdown 下载，读取原记录，不调用模型重新生成；接口保留用户归属校验。
- 继续过滤内部检查项，不加入“查看地图”位置功能。

## 接入与成本

铁路使用现有 12306 MCP；高德地点与天气使用现有 HTTP API，业务能力并不要求全部换成 MCP。实际能力取决于数据、权限、时效和错误处理，不取决于 MCP 数量。

本次排查发现本地铁路 MCP 未监听配置端口，已复用项目已有的 0.3.10 缓存启动，完成握手与工具清单检查：共8个工具，包含车站及车次查询。该检查不代表替用户选定日期或查询到了本次可购买车票。

现有 `search_web` 已进入规划检索链路：配置 `TAVILY_API_KEY` 后每次规划最多增加一次网页检索，将公开资料作为参考，而不是自动认证价格或营业状态。本机目前未配置此项，离线测试验证了接入及回退，不声称已经连通新的酒店、餐厅供应商。

新酒店或餐饮 MCP 应在明确供应商、密钥、费用和许可后再接入。当前不新增数据库、ORM或服务商账号，也不将任何工具声明当成真实预订或出票保证。

高德天气实连诊断成功，返回3个日期的预报。诊断不代表用户已选定这些日期，正式攻略仍按用户的出发日期查询。

全费用人民币预算提供可调整的预留额度：往返交通40%、住宿20%、餐饮25%、门票及市内交通5%、机动资金余量。分项合计等于总预算。这是消费规划，不是实际报价；自定义或排除住宿的范围不套用该模板。

高德餐饮地点查询实连成功，返回5个候选。片区筛选提示词已要求美食偏好同时核对用餐地点；门店地址匹配不等于营业、价格或可订座位已核实，缺少依据时仅推荐菜品与片区。
