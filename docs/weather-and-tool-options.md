# 天气接入与后续工具选择

2026-11-03：天气使用现有AMAP_API_KEY，先行政区精确匹配，再查询天气。每次可查询规划最多30天，但只使用实际返回的短期预报；远期直接返回out_of_range，不猜测天气。匹配日期不足返回missing_dates。缺密钥、服务失败、城市歧义和空结果分别降级。默认规划日期已知时取证；日期未知跳过。预报进入研究上下文与证据，已保存攻略的天气区块和PDF共用快照。天气依据按现有1小时策略过期，仅为预报参考。一次执行最多一次行政区查询和一次天气查询，不按行程天数逐天调用。

优先级建议：步行/公交路线及景区预约核实优先，其次补航班查询。铁路已有第三方MCP查询，优先改进班次与首末日行程衔接，保留官方下单核实。航班应走授权OTA/聚合平台，区分时刻、实时可售价格和行李/退改规则，不以航班存在当作可出票报价。

酒店当前先提供住宿片区与真实POI候选，明确未核实房态价格；收集入住/离店日期、人数房间数、预算及交通偏好，再做排序。公开点评页面不等于可批量调用的授权数据API。正式实时房价库存建议等到有稳定住宿查询和点击/预订意向后接入。

美团直连平台是供应商/OTA/PMS数据对接，不能把它误当面向消费者的酒店搜索接口。其FAQ公开默认供应商每分钟60次、接口级20次/秒，累计超限200次可能拒绝10分钟；这些是直连文档规则，不是本项目未来分销合同额度：https://openplatform-hotel.meituan.com/portal/faq 。正式合作应分别询问搜索、详情、验价和订单的限流、峰值、缓存许可、计费、佣金结算及退款责任。

评估账本：月成本=固定合作费+计费请求量×单价+开发维护与客服成本；订单贡献=有效成交数×每单净佣金。用实际询价、点击与成交数据判断，不能用未经验证的流量预估承诺回本。现在可先了解准入并埋点，交易API等实际需求出现后再投入。轻量跳转/H5合作通常比自建交易链路更适合早期验证，但仍需平台许可与具体报价。
